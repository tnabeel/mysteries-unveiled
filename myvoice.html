Instructions

  1. If myVoice is already installed, this link will try to open it automatically. If it does not open, tap “Open in myVoice” above and go to step 4. Otherwise, tap “Download myVoice app” above and install it directly from this page.
  2. If Play Protect warns you, do not worry. This app is not on Play Store, so Android warns for every app installed this way. Tap “More details”, then “Install anyway”.
  3. Open myVoice and allow Microphone when it asks.
  4. Enter your name and the channel name shown on this page.
  5. Tap “Join”.
  6. Hold the button to talk, release it to listen. You can also use “Tap to Talk” and “Tap to Stop”.
  7. Your microphone is used only while you are talking. When you are not talking, myVoice releases the microphone, so you can also send WhatsApp voice messages.

myVoice asks only for Microphone (to talk) and Internet (to connect) — no contacts, SMS, location, camera or files. No account is needed.

Please share channel links only privately — anyone with the channel name can join.
